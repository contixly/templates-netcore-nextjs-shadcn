# Глоссарий

Эти термины описывают текущий целевой шаблон. Исторические страницы могут упоминать прежнюю
full-stack реализацию Next.js; считайте такое поведение legacy, если актуальная страница явно не
подтверждает обратное.

## Архитектура и маршрутизация

| Термин                    | Значение                                                                                                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Шаблон                    | REST API на .NET 10 и ASP.NET Core и отдельный UI Next.js с persistence в PostgreSQL, аутентификацией, рабочими пространствами, API-ключами, локализованной документацией и quality gates. |
| `Template.Api`            | Единственный HTTP host. Он владеет `/api/**`, композицией Minimal API, HTTP-валидацией, аутентификацией, авторизацией и преобразованием ответов.                                           |
| `Template.Domain`         | Доменные value objects и правила без зависимостей от инфраструктуры или HTTP.                                                                                                              |
| `Template.Application`    | Сценарии использования, application models и порты. Зависит только от Domain.                                                                                                              |
| `Template.Infrastructure` | Реализации портов Application/Domain, включая persistence EF Core, Identity, OpenIddict Client, криптографию и хранилище поиска документов.                                                |
| Endpoint module           | Реализация `IEndpointModule`, которая подключает одну возможность API через общие группы routes.                                                                                           |
| REST-граница              | Единственная граница продуктовых данных между Next.js и ASP.NET Core. В web-приложении нет Server Actions или API Route Handlers для продуктовых данных.                                   |
| Same-origin topology      | Схема развертывания, где браузерные страницы и `/api/**` используют один origin; локальный Next.js применяет `API_PROXY_TARGET`, а в production API остается во владении ASP.NET Core.     |
| Оболочка приложения       | Layouts, навигация и защищенные экраны Next.js, построенные по REST projections.                                                                                                           |

## Аутентификация и безопасность

| Термин                                  | Значение                                                                                                                                                              |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Браузерная сессия                       | Аутентифицированная сессия ASP.NET Core, представленная в браузере защищенной HttpOnly cookie и поддерживаемая persistent ticket в PostgreSQL.                        |
| HttpOnly cookie                         | Cookie, автоматически передаваемая браузером, но недоступная JavaScript. UI не копирует ее в browser storage.                                                         |
| CSRF token                              | Свежий request token из `GET /api/v1/auth/csrf`, отправляемый как `X-CSRF-TOKEN` для небезопасных браузерных операций.                                                |
| OpenIddict Client                       | OAuth client integration в ASP.NET Core. Это не authorization server; access и refresh tokens провайдера не сохраняются.                                              |
| Локальная авторизация для автоматизации | Доступный только в Development/Test flow ASP.NET Core для сгенерированных пользователей и сессий Playwright. В Production он недоступен даже при установленном флаге. |
| OAuth-провайдер                         | Один из настроенных внешних providers входа, объявленных API. Provider отсутствует, если его обязательная локальная configuration неполна.                            |
| Подключенный аккаунт                    | Сохраненная связь пользователя с внешней provider identity.                                                                                                           |
| Опасные действия                        | UI аккаунта для разрушительных операций, например удаления текущего пользователя.                                                                                     |

## Рабочие пространства

| Термин                              | Значение                                                                                                                        |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Рабочее пространство                | Пользовательская граница совместной работы, основанная на organization aggregate ASP.NET Core и записях PostgreSQL.             |
| Организация                         | Backend tenant, владеющий участниками, ролями, командами, приглашениями, разрешенными доменами email и API-ключами организации. |
| Ключ организации                    | Slug или UUID, принимаемый `/w/{organizationKey}/...`; разрешенные страницы перенаправляются на текущий канонический slug.      |
| Активное рабочее пространство       | Доступная организация, сохраненная в текущей persistent browser session и используемая resolver `/dashboard`.                   |
| Участник                            | Пользователь, связанный с организацией встроенной ролью owner, admin или member.                                                |
| Команда                             | Явная подгруппа участников организации. У новой организации может корректно не быть ни одной команды.                           |
| Приглашение                         | Ограниченный запрос email-получателю присоединиться к организации, необязательно с выбранной командой.                          |
| Разрешенные домены email            | Политика организации для решений о приглашении и прямом добавлении участника.                                                   |
| Онбординг без рабочего пространства | Сценарий `/welcome` для аутентифицированного пользователя без доступной организации.                                            |

## API и сгенерированные контракты

| Термин                   | Значение                                                                                                                                                      |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| API v1                   | Версионированные операции в `/api/v1`; каждый route объявляет доступ по браузерной сессии, API-ключу, в смешанном или анонимном режиме.                       |
| API-ключ                 | Одноразово показываемая машинная credential в `x-api-key`; она не хранится в browser storage и не помещается в URL.                                           |
| Scope                    | Конкретное право, проверяемое при операции с API-ключом.                                                                                                      |
| Success envelope         | Типизированная JSON-форма `{ data: ... }`. Paginated collections помещают `items` и `nextCursor` внутрь `data`.                                               |
| Problem Details          | Ошибка `application/problem+json` с обязательными RFC-полями, стабильным `code` и безопасным `traceId`; validation также содержит `errors`.                   |
| OpenAPI contract         | Зафиксированное описание `contracts/openapi/v1.json`, экспортированное из `Template.Api`.                                                                     |
| Сгенерированный REST SDK | Зафиксированный TypeScript client в `apps/web/src/lib/api/generated`, создаваемый из OpenAPI и используемый web adapters.                                     |
| Непрозрачный cursor      | Выданное сервером значение pagination, которое клиент возвращает без изменений; его нельзя декодировать, редактировать или использовать для другой коллекции. |

## Документация и качество

| Термин                        | Значение                                                                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Вариант локали                | Исходный файл `.en.md`/`.ru.md` или `.en.mdx`/`.ru.mdx` для одного канонического URL документации.                                          |
| Канонический URL документации | Route `/docs/...` без суффикса локали и расширения исходного файла.                                                                         |
| Content compiler              | Детерминированные scripts, которые проверяют metadata, пары локалей, ссылки, изображения и MDX syntax и генерируют registry и search index. |
| Закрытый набор MDX            | Фиксированный allow-list специальных компонентов документации; imports, exports и неизвестные компоненты отклоняются.                       |
| `content:check`               | Команда, которая повторяет compilation документации и побайтно сравнивает оба зафиксированных сгенерированных артефакта.                    |
| `PUBLIC_DEFAULT_LOCALE`       | Общий для deployment выбор `en` или `ru` для UI и документации; невалидные значения приводят к fallback `en`.                               |
| OpenSpec                      | Инициализированное, но сейчас неактивное пространство спецификаций. Активных capability или change нет до возможного явного запроса.        |
| `WebApplicationFactory`       | Integration-test host ASP.NET Core для проверки HTTP endpoints без создания второго host приложения.                                        |
| `Template.E2EHost`            | Test orchestrator, который создает одноразовую PostgreSQL, применяет migrations и запускает настоящий `Template.Api` для Playwright.        |
