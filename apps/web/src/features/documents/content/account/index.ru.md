# Настройки аккаунта

Настройки аккаунта - глобальная область пользователя с активной сессией. ASP.NET Core владеет API аккаунта и аутентификации; Next.js использует сгенерированный REST-клиент. Браузер подтверждает сессию защищенной same-origin HttpOnly cookie `__Host-template.session`, а не bearer-токеном в браузерном хранилище или прямым чтением базы.

## Разделы аккаунта

| Раздел           | Маршрут             | REST-поверхность                                                           |
| ---------------- | ------------------- | -------------------------------------------------------------------------- |
| Профиль          | `/user/profile`     | `GET /api/v1/account` и `PATCH /api/v1/account/profile`.                   |
| Подключения      | `/user/connections` | Список связей, внешний challenge и отключение провайдера.                  |
| Безопасность     | `/user/security`    | Список сессий и endpoints отзыва одной/остальных сессий.                   |
| Приглашения      | `/user/invitations` | `GET /api/v1/account/invitations`.                                         |
| API-ключи        | `/user/api-keys`    | Отдельно документированное управление персональными ключами для `/api/v1`. |
| Опасные действия | `/user/danger`      | Подтвержденный `DELETE /api/v1/account`.                                   |

Все проекции аккаунта используют `Cache-Control: no-store`. Для небезопасной операции UI получает свежий токен через `GET /api/v1/auth/csrf` и отправляет его с cookie; API аутентифицирует, валидирует и авторизует на HTTP-границе.

## Текущее состояние реализации

Итерации 3-4 реализуют постоянные сессии Identity, жизненный цикл аккаунта и пять внешних OAuth-провайдеров. Production-регистрация/сброс/смена пароля, 2FA и ручная верификация email намеренно не реализованы. Access- и refresh-токены провайдеров не сохраняются, а локальное отключение не отзывает внешнее разрешение.

Настройки аккаунта предназначены для персональных данных и доступа, настройки пространства - для участников, команд, приглашений и доменов организации.
