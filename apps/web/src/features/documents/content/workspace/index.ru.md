# Рабочее пространство

Рабочее пространство - пользовательское представление организации ASP.NET Core. Организации, участия, команды, приглашения и предпочтение активной сессии сохраняет API; Next.js использует сгенерированный REST-клиент.

## Модель

| Термин               | Значение                                                                      |
| -------------------- | ----------------------------------------------------------------------------- |
| Организация          | Tenant-граница с UUID id, каноническим slug, настройками и участиями.         |
| Рабочее пространство | UI организации под `/w/:organizationKey/...`.                                 |
| Ключ организации     | UUID или slug для поиска; deep link канонизируется к текущему slug.           |
| Участие              | Связь пользователя ровно с одной ролью `owner`, `admin` или `member`.         |
| Активная организация | Nullable-предпочтение постоянной сессии, а не браузерный или командный токен. |

`GET /api/v1/organizations` возвращает доступные организации. `GET /api/v1/organizations/by-key/{organizationKey}` проверяет доступ и отдает канонический ключ и capabilities. Отсутствующие и чужие ресурсы не раскрываются.

## Что могут делать пользователи

- создать организацию/участие owner через `POST /api/v1/organizations`;
- выбрать ее через `PUT /api/v1/auth/session/active-organization`;
- обновить/удалить согласно capabilities;
- постранично читать и управлять участниками, командами и 48-часовыми приглашениями по фиксированной матрице ролей.

Итерации 5-6 реализуют организации, участия, онбординг, команды и приглашения. Пользовательские роли, удаление участника организации, активная команда, отмена/повтор приглашения и реальная email-доставка вне scope.
