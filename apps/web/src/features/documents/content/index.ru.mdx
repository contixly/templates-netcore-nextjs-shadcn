# Документация шаблона

Шаблон состоит из двух приложений. ASP.NET Core 10 — единственный HTTP-хост для `/api/**`; он
владеет аутентификацией, авторизацией, бизнес-сценариями, хранением данных и OpenAPI. Отдельное
приложение Next.js отвечает за отображение и взаимодействие в браузере и получает продуктовые
данные только через сгенерированный REST SDK.

Браузерная сессия остается в защищенной same-origin cookie с `HttpOnly`. UI не хранит bearer-токены,
не вызывает Server Actions для продуктового поведения, не размещает продуктовые API Route Handlers,
не использует Better Auth или Prisma и не обращается к базе напрямую.

## Что входит в текущий шаблон

- **Слоистый backend на .NET 10**: `Template.Domain`, `Template.Application`,
  `Template.Infrastructure` и единственный HTTP-хост `Template.Api`.
- **REST-only граница web**: отдельный UI Next.js использует зафиксированный OpenAPI-контракт через
  сгенерированные операции и DTO.
- **Аккаунты и сессии**: аккаунты на ASP.NET Core Identity, постоянные сессии, опциональные внешние
  OAuth-подключения, CSRF-защита и защищенные same-origin cookie.
- **Организации и совместная работа**: канонические маршруты рабочих пространств, фиксированные роли,
  участники, команды, приглашения, политика email-доменов и онбординг без рабочего пространства.
- **API-доступ**: персональные API-ключи и ключи организаций, одноразовый показ секрета, ротация,
  права, срок действия, ограничения частоты и поддерживаемые read-only маршруты `/api/v1`.
- **Публичная документация**: канонические маршруты `/docs/**`, варианты на русском и английском,
  поиск, история релизов и еженедельные записи.
- **Процесс качества**: unit-тесты .NET и тесты через `WebApplicationFactory`, Jest, Playwright,
  детерминированные артефакты OpenAPI и документации и проверки границ.

<Callout title="Актуальное руководство и история" variant="info">
  Разделы аккаунта, рабочего пространства, API, приложения и разработки
  описывают мигрированную архитектуру. История сохраняет фактические события
  прежнего full-stack эталона Next.js и явно помечает его Prisma, Better Auth,
  Server Actions, API-маршруты и кеширование как legacy, а не как текущие
  инструкции.
</Callout>
